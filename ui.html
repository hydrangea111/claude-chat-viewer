대기 중

도움말

단축어(/) 쓰는 법

  1. 1입력창 맨 앞에 / 를 치면 목록이 나옵니다.
  2. 2↑↓ 로 고르고 Tab 이나 Enter 로 넣습니다.
  3. 3뒤에 하고 싶은 말을 붙여 보냅니다.
    예: /code-review 최근 변경

많이 쓰는 단축어

일반적으로 많이 쓰는 순서입니다(이 PC의 사용 횟수를 센 건 아닙니다). 설치·계정에 따라 없을 수도 있습니다.

/code-review바뀐 코드를 검토해서 버그를 찾습니다. /simplify바뀐 코드를 더 간단하고 깔끔하게 정리합니다. /init프로젝트 설명 파일(CLAUDE.md)을 만듭니다. /security-review바뀐 내용의 보안 점검. /loop일정 간격으로 같은 일을 반복합니다. /schedule정해진 시간에 자동으로 실행합니다. /fewer-permission-prompts허용 확인 횟수를 줄이는 설정을 제안합니다. /run앱을 실행해서 바뀐 게 동작하는지 확인합니다. /claude-apiClaude API·모델 관련 질문.

터미널 명령은 이렇게 바꿔 쓰십시오

/model입력창 위의 모델 버튼. /effort입력창 위의 생각 깊이 버튼. /clear왼쪽 위의 ＋ 새 대화. /resume왼쪽 대화 목록에서 고르기. /login터미널(cmd)에서 claude 를 실행한 뒤 입력.
알아 두면 좋습니다
이름:앞글자 형태(예: engineering:debug)는 설치된 플러그인의 기능입니다. 직접 만든 단축어는 ~/.claude/commands, ~/.claude/skills 폴더에서 읽고, 대화를 한 번 하면 Claude Code가 알려 준 정확한 목록으로 바뀝니다. 터미널 전용 명령(/compact /config 등)은 여기서 동작하지 않아 목록에서 뺐습니다.

메시지가 떴을 때

"로그인이 풀렸습니다"터미널(Win+R → cmd)에서 claude 를 실행하고 /login 을 입력해 로그인한 뒤, 뷰어로 돌아와 다시 보내십시오.
"인터넷에 연결되지 않았습니다"인터넷·VPN·회사 네트워크를 확인하십시오. 보내려던 말은 입력창에 돌려놓습니다.
"사용량 한도에 걸렸습니다"한도가 풀릴 때까지 기다리십시오. 제목 아래 한도 줄(마지막 응답 기준)을 참고하십시오.
"서버가 혼잡합니다"잠시 뒤에 다시 보내십시오.
모델을 쓸 수 없다는 오류계정에 없는 모델일 수 있습니다. 모델 버튼에서 기본이나 다른 모델을 고르십시오.

기능이 안 될 때

선택 버튼이 안 나옵니다Claude가 선택지를 정해진 형식으로 쓰지 않은 경우입니다. 입력창에 직접 답하십시오.
웹 검색이 안 됩니다웹 검색 스위치를 켜십시오. 꺼져 있으면 읽기만·파일 수정 모드에서는 막힙니다.
브라우저 연결이 안 됩니다브라우저 스위치를 켜고, Chrome에 Claude 확장 프로그램이 설치·연결돼 있는지 확인하십시오.
Claude Code가 없다고 나옵니다Claude Code를 설치하고 로그인한 뒤 뷰어를 다시 여십시오. 설치하는 방법.
exe가 Windows에 막힙니다"애플리케이션 제어 정책…"으로 막히면 Python으로 실행하는 방법을 보십시오.
창이 늦게 뜹니다PC가 느리거나 처음 실행할 때는 최대 수십 초 걸릴 수 있습니다. 잠시 기다려 주십시오.

허용 범위

읽기만은 파일을 읽고 검색만 합니다. 파일 수정은 이 대화의 폴더 안에서 파일을 만들고 고칠 수 있습니다. 모두 허용은 확인 없이 파일 수정과 명령 실행까지 합니다. 믿을 수 있는 폴더에서만 쓰십시오.

생각 깊이

Claude가 답하기 전에 얼마나 깊게 생각할지 정합니다. 높을수록 신중하지만 느리고 사용량이 많이 늡니다. 평소엔 기본이면 충분합니다.

"다음부터 보지 않기"

파일 수정·모든 도구 허용·브라우저 켜기를 누를 때 나오는 확인창에서 "다음부터 이 확인창 보지 않기"를 고르면 그 확인창이 다시 나오지 않습니다.

기억되는 설정

허용 범위, 웹 검색, 브라우저, 모델, 생각 깊이는 뷰어를 껐다 켜도 마지막 선택이 유지됩니다.

새 버전 알림

시작할 때 웹사이트의 작은 파일(version.json) 하나를 내려받아 새 버전이 있는지만 확인합니다. 내 정보는 보내지 않습니다. 새 버전이 있으면 위에 안내 줄이 뜹니다.

응답 중지

Claude가 답하는 동안 Esc를 누르면 중지 버튼과 같이 응답을 멈춥니다. 창이나 메뉴가 열려 있으면 Esc는 먼저 그것을 닫습니다.

음성 대화

입력창 위 옵션 메뉴에서 🔊 읽어 주기를 켜면 Claude의 답이 끝날 때 Windows 한국어 음성으로 읽어 줍니다. 코드와 주소는 읽지 않고, Esc를 누르면 멈춥니다.

입력창 오른쪽의 🎙 버튼을 누르면 마이크로 말해서 대화합니다. 말을 마치고 잠시 쉬면 글자로 바꿔 보내고, 답을 읽는 동안에는 듣기를 멈췄다가 다시 듣습니다. 처음 켤 때 음성 인식 프로그램과 한국어 모델(약 200MB)을 한 번 내려받으며, 인식은 이 PC 안에서만 이루어지고 음성은 밖으로 나가지 않습니다.

대화 모드

옵션 메뉴의 💬 대화 모드를 켜면 말풍선이 커지고, 파일 읽기·명령 같은 도구 작업은 "작업 N개 보기" 한 줄로 접힙니다. 입력창 위에는 듣는 중 · 생각하는 중 · 말하는 중을 보여 주는 표시가 나옵니다. 🎙 마이크와 🔊 읽어 주기와 함께 쓰면 말로 주고받기 편합니다.

토큰·한도 줄

토큰 줄은 이 대화에서 쓴 양입니다. 한도 줄은 계정 전체의 사용률이고, 마지막 응답을 받은 시점의 값이라 대화하지 않는 동안에는 갱신되지 않습니다. 80% 이상이면 빨갛게 보입니다. 한도 줄에 마우스를 올리면 초기화 시각이 나오고, 그 시각이 지나면 자동으로 0%로 바뀝니다.

불편한 점, 오류, 바라는 기능을 적어 보내 주십시오. 개발자가 읽고 개선에 참고합니다.
