도움말

단축어(/) 쓰는 법

입력창 맨 앞에 /를 치면 쓸 수 있는 목록이 나와요. ↑↓로 고르고 Tab이나 Enter로 넣은 뒤, 뒤에 하고 싶은 말을 붙여 보내세요. 예: /code-review 최근 변경

  • 이름:앞글자 형태(예: engineering:debug)는 설치된 플러그인의 기능이에요.
  • 직접 만든 단축어는 ~/.claude/commands, ~/.claude/skills 폴더에서 읽어요.
  • 목록은 대화를 한 번 하면 Claude Code가 알려 준 정확한 목록으로 바뀌어요.
  • 터미널 전용 명령(/clear /compact /config 등)은 여기서 동작하지 않아서 목록에서 뺐어요. 대신 모델과 생각 깊이는 입력창 위 버튼으로 고르고, 새 대화는 ＋ 새 대화로 시작하세요.

확인창 "다음부터 보지 않기"

파일 수정·모든 도구 허용·브라우저 켜기를 누를 때 나오는 확인창에서 "다음부터 이 확인창 보지 않기"를 고르면 그 확인창이 다시 나오지 않아요. (브라우저는 확인창만 생략되고, 뷰어를 다시 열면 꺼진 상태로 시작하는 건 그대로예요.)

생각 깊이란?

Claude가 답하기 전에 얼마나 깊게 생각할지 정해요. 높을수록 신중하지만 느리고 사용량이 많이 늘어요. 평소엔 기본이면 충분해요.

오류가 났을 때

  • "로그인이 풀렸어요": 터미널(Win+R → cmd)에서 claude를 실행하고 /login을 입력해 로그인한 뒤, 뷰어로 돌아와 다시 보내세요.
  • "인터넷에 연결되지 않았어요": 인터넷·VPN·회사 네트워크를 확인하세요. 보내려던 말은 입력창에 돌려놔요.
  • "사용량 한도에 걸렸어요": 한도가 풀릴 때까지 기다리세요. 제목 아래의 한도 사용률(마지막 응답 기준)을 참고하세요.
  • "서버가 혼잡해요": 잠시 뒤에 다시 보내세요.
  • 모델을 쓸 수 없다는 오류: 계정에 없는 모델일 수 있어요. 모델 버튼에서 기본이나 다른 모델을 고르세요.
  • 선택 버튼이 안 나와요: Claude가 선택지를 정해진 형식으로 쓰지 않은 경우예요. 입력창에 직접 답하세요.
  • 웹 검색이 안 돼요: 🔎 웹 검색 스위치를 켜세요. 꺼져 있으면 읽기만·파일 수정 모드에서는 막혀요.
  • 브라우저 연결이 안 돼요: 🌐 브라우저 스위치를 켜고, Chrome에 Claude 확장 프로그램이 설치·연결돼 있는지 확인하세요.
  • Claude Code가 없다고 나와요: Claude Code를 설치하고 로그인한 뒤 뷰어를 다시 여세요.
  • exe가 Windows에 막혀요(애플리케이션 제어 정책): 파이썬으로 실행하는 방법을 보세요.
